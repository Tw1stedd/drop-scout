📖 How to set up Firebase (free)
  1. Go to Firebase Console
  2. Click Create a project (any name)
  3. Go to Build → Realtime Database
  4. Click Create Database
  5. Choose location, click Next
  6. Select "Start in test mode", click Enable
  7. Copy the database URL (looks like https://xxx.firebaseio.com)
  8. Paste it above and click Test → Save
